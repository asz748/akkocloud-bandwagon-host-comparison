## 流量口径：500GB 是上下行合计

AkkoCloud 官方标的是双向计费，500GB 指上传加下载的总和。跑下载、做镜像站这类下行吃满的场景，实际能用的量比标称数字少一半左右。搬瓦工 CN2 GIA-E 同档标 1TB，两家的计费口径不完全一致，别只比数字大小。

按套餐阶梯看，AkkoCloud 给流量的方式是逐档加的：A1 月付 600GB，A1 mini 500GB，A2 系列 800–1000GB，B1 系列 1.2–1.5TB。个人博客、轻量 API、跨境工具这类应用一个月跑几百 GB 很宽裕；要挂下载或者做中转节点，直接跳到 B1 mini 年付 ¥699（1.2TB），比在 A1 上反复超流量划算。

## 线路和延迟：三网回程都走 CN2 GIA

AkkoCloud 全线三网回程强制 CN2 GIA，走 59.43 网段，不挤 202.97 的普通出口。去程分机房有差别：

- **圣何塞**：电信去程 59.43 CN2 GIA，联通走 AS9929，移动直连；平均延迟约 168ms，非高峰下载能到 6MB/s
- **法兰克福**：电信、联通去程 GIA，移动直连；延迟有测评实测 163ms，另一些测评站记录在 180ms 上下，普通欧洲 VPS 通常 230ms 以上
- **伦敦**：电信、联通去程 GIA；延迟约 200ms，下载能跑到 60Mbps

搬瓦工洛杉矶 CN2 GIA 到国内普遍在 150–180ms，晚高峰丢包控制是它口碑的来源，这一点第三方测评的说法比较一致。

欧洲方向的 CN2 GIA 是 AkkoCloud 真正的差异点。市面上做美西 CN2 GIA 的商家一抓一把，德国法兰克福和英国伦敦还能走 CN2 GIA 回国的屈指可数。面向欧洲用户建站、需要欧洲 IP 做本地化业务，这类需求在搬瓦工那边只能看荷兰节点，价格更高且经常缺货。

## 下单前必须确认的四件事

**1. 不支持退款。** 服务条款里写明了不退款，"分到的不是原生 IP"这类理由也不受理。下单前把这台机器当成不可退的支出来判断。

**2. 不保证原生 IP。** 官方明确说明不保证原生 IP，Looking Glass 上的测试 IP 也不代表你实际会分到的 IP 段。能不能解锁 Netflix 取决于实际分配，买之前无法确认。对原生 IP 有硬性要求的话，这家不合适。

**3. 只支持支付宝。** 国际信用卡目前不支持，境外用户付款会有障碍。

**4. IP 不是想换就能换。** 2026 年 6 月官方公告说 IPv4 资源严重紧缺，暂停受理除英国以外的 IP 更换请求，美国和德国的机器暂时换不了 IP；后续是否恢复要看官方通知。搬瓦工那边换 IP 是收费功能、机房切换也换 IP 段，这一点上两家的政策差别很大，买之前想清楚 IP 被封之后你打算怎么办。

看中哪个机房，先用官网提供的 Looking Glass 测一遍路由和延迟（圣何塞、法兰克福、伦敦三地各有一个测试入口），确认你本地三网的走向符合预期，再付款。
